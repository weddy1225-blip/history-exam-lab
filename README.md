# 高中歷史科線上測驗

這是一份可部署至 GitHub Pages 的 20 分鐘高中歷史申論測驗。學生端在
作答前維持一般考試外觀；提交後才顯示歷史成績、逐題簡評及提示碼防禦結果。

## 功能

- 暱稱與組別驗證
- 8 題長篇史料申論、20 分鐘倒數與自動交卷
- 答案暫存、題目導覽及送出前檢查
- 可解釋的史實／概念／因果評分
- 「馬達加斯加」完整詞、英文詞及殘缺變形偵測
- 個人排行榜，顯示團隊成員填寫的完整暱稱與組別
- Google Apps Script＋Google 試算表集中保存結果
- 無須在 GitHub 放置 API 金鑰或個人作答資料

## GitHub Pages

網站是純靜態 HTML、CSS 與 JavaScript，直接以儲存庫根目錄部署即可。
GitHub Pages 應設定為從 `main` 分支根目錄發布。

## 成績後端

1. 建立 Google 試算表。
2. 建立 Google Apps Script 專案，把 `apps-script/Code.gs` 貼入。
3. 在 Apps Script「指令碼屬性」新增 `SHEET_ID`，值為試算表 ID。
4. 將網頁應用程式部署為「以我執行」，存取權設為允許考生提交。
5. 將部署網址填入 `config.js` 的 `apiUrl`。

Apps Script 會在伺服器端重新評分，不信任瀏覽器傳來的分數。試算表保存完整
暱稱、組別、答案及評語；排行榜只回傳暱稱、組別、分數與防禦結果。

## 隱私與金鑰

- 不在前端、GitHub 或 Git 歷史放置任何 API 金鑰。
- 暱稱、答案與完整成績只存於專案擁有者的 Google 試算表。
- `.env*`、憑證、快取與本機設定均由 `.gitignore` 排除。
- `config.js` 只包含可公開的網頁應用程式網址與測驗代碼。

## 本機測試

可用任何靜態伺服器開啟，例如：

```text
python -m http.server 8080
```

再瀏覽 `http://localhost:8080/`。未設定 `apiUrl` 時，排行榜只保存在目前瀏覽器，
便於離線測試。

## 檔案

- `index.html`：頁面結構
- `styles.css`：響應式介面
- `app.js`：考試、計時、評分與排行榜
- `config.js`：公開部署設定（不得放金鑰）
- `apps-script/Code.gs`：集中保存與伺服器端重新評分
- `企編-題庫與評分規格.md`：題庫及配分依據
- `美編-介面規格.md`：視覺與可用性規格
