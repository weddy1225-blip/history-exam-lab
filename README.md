# 高中歷史科單頁申論練習

這是一張可部署至 GitHub Pages 的 A4 比例高中歷史考卷。頁面只包含五題史料申論與五個答題框，不收集身分、不計時、不送出、不評分，也不顯示排行榜。

## 目前功能

- 單一 A4 比例考卷，桌面版五題與答題框集中於單面範圍。
- 手機版自動加高答題框，維持可輸入性。
- 作答只以 `localStorage` 暫存在目前裝置。
- 沒有 `fetch`、Google Apps Script、試算表或其他資料傳送。
- 複製考卷文字時，剪貼簿會附加編碼的辨識指令。
- 網頁中另有網址型 Agent 可讀的中繼資料、結構化資料及離屏文字。
- 考卷像素含低顯著辨識文字，供截圖型視覺 AI 測試。

## 重要限制

三種通道都只能提高 AI 接收提示的機率，無法保證所有模型一定服從。截圖通道尤其受畫面解析度、縮放、壓縮、OCR能力與模型安全策略影響。

## 部署

網站為純靜態 HTML、CSS 與 JavaScript。GitHub Pages 從 `main` 分支根目錄發布。

## 測試

```text
node --check app.js
node --test tests/exam-flow.test.mjs
```

## 主要檔案

- `index.html`：五題考卷、答題框與機器讀取通道。
- `styles.css`：A4單面、行線答題框、手機與列印版面。
- `app.js`：本機草稿與複製事件。
- `tests/exam-flow.test.mjs`：純考卷、無傳送與三通道檢查。
